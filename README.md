      <p>An AI-powered vehicle body-type classification system that fine-tunes <b>EfficientNet-B0</b> to identify 7 vehicle body types (convertible, coupe, hatchback, pickup, sedan, SUV, van) — hitting <b>96.76% test accuracy</b>.
